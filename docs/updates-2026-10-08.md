# 2026-10-08 更新说明：LX06 1.94.14、本地退出与空白纠错表

这是整理供提交/评审的改动，不是已发布的 Release，也不改变项目包版本号。基线：OwnDing `main` 的 `5d8033387db245eab4151e0af85ad472eab8858d`。

## 新增 / 修复

1. **LX06 1.94.14 同版本校验构建**：新增 profile 和离线构建入口。校验完整 OTA/rootfs 摘要和原有补丁哈希，按实际音频库偏移修改，拒绝错误版本和分区超限；随机 SSH 密码不打印、不提交。使用方法和验证范围见 [LX06 说明](lx06-1.94.14.md)。
2. **配置化退出短语**：桥接在收到 STT 后精确匹配 `local_exit_commands`，支持标点/空格归一化。没有开启后端完整意图识别，不把“关闭主卧灯”等正常控制句当退出。
3. **退出后保持待命**：退出前原子设置关闭标记、取消旧等待并走已有打断路径；丢弃迟到的 STT/TTS/LLM/音频包，直到显式再次唤醒。避免“说退出了，却被后续 tts stop 再次开启监听”。静音超时退出也使用关闭标记，保留作者新加入的 KWS 重置及健康日志。
4. **部署与说明**：Compose 增加新匹配模块的只读挂载，README/刷机说明增加准确入口、ARM32 用户态提醒、自定义 SSH 密码说明。
5. **空白识别后纠错表**：新增 `examples/xiaozhi/asr-corrections.json`，默认关闭、规则为空。个人规则可放入 Git 忽略的 `.local.json`；桥接展示和 Hermes provider 的模型入口都接入纠错。支持整句精确匹配/字面名称替换、冲突/坏配置回退、常见控制词/数字基础保护；不是声学热词，也不改变 KWS。[填写与挂载说明](../examples/xiaozhi/README.md#可配置的识别后纠错表)

## 不属于本次新增

仓库本来已有 LX06 机型支持、原生小爱 TTS、录音/播放缓冲修正、Hermes、HA 和 DeepSeek 接入；本次不重复署为新增，不覆盖作者最近的二进制音频协议、自动化或主动播报功能。

个人“小七同学”名称作为可配置示例保留，未把所有用户的默认唤醒词改成一个名字。Windows 开机启动、路由器/WOL、Codex CLI 桥接和家庭设备列表未纳入此包：包含本机权限/路径或尚未完成通用安全验证，需要另行整理和评审。

## 使用本地退出

默认可说“退出对话”“结束聊天”“再见小七”；配置例子和回归测试命令见 [小智接入说明](../examples/xiaozhi/README.md#本地退出对话)。退出后不继续追问，重新说配置的唤醒词才能恢复。

**限制要明确**：短语需要先由小智 ASR 识别，因此不是“在播放时任何一句话都能实时打断”。当前方案说“小爱同学”仍是播放期间的原生打断入口。另外后端通常在发送 STT 后立刻安排模型任务，桥接收到退出词再发 abort 会有竞态；本次保证不再播报/恢复监听，**不保证后端绝对没有发出模型请求或没有消耗 token**。
